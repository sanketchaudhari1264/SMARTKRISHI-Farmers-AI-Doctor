# Public Assets Folder

Place your images in this folder to use them in the website.

## Required Images:

### Hero Section (Home Page):
- `plant-hand.jpg` - Image of a hand holding a plant seedling (main hero image)

### Steps Section (Home Page):
- `step1.jpg` - Step 1 placeholder image
- `step2.jpg` - Step 2 placeholder image
- `step3.jpg` - Step 3 placeholder image
- `step4.jpg` - Step 4 placeholder image
- `step5.jpg` - Step 5 placeholder image

## Usage:

Reference images in your code like this:
```jsx
<img src="/plant-hand.jpg" alt="Description" />
```

The `/` at the start refers to the `public` folder.

## Recommended Image Specifications:

- **Hero Image**: 800x600px minimum, JPG or PNG
- **Step Images**: 400x300px minimum, JPG or PNG
- Keep file sizes optimized (under 500KB for web performance)
